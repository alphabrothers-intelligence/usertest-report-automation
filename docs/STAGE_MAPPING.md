## 데이터셋별 특이사항

- **리바랩스** — 유일하게 `S7 사용자 경험 품질 평가`(실용성1~4 · 즐거움1~4) 보유. 순위 대상이 기능명이라 사분면 성립
- **케어클** — 유일하게 `S4 고객 여정 기반 경험 평가`(5시점) 보유. 순위 대상이 구매요소명이고 기능명과 교집합 0이라 사분면 불가
- **이젠오토** — 순위 문항 자체가 없음. `S6 4대 가치` 안에 `가장 인상 깊었던 기능` 문항이 섞여 있음. 헤더 `(copy)` 중첩으로 기능명이 훼손돼 보고서 Q9~Q16 기준 재매핑 필수
- **정리습관** — 기능이 아닌 신청 플로우 22열. 4대 가치 대신 커스텀 4축(사용 편의성·서비스 신뢰도·가격·소요시간). 36·37열 헤더가 완전히 동일한데 값 유형이 다름(척도 vs 자유서술)
- **투블럭에이아이** — 기능 순위와 구매요소 순위를 **둘 다** 보유. 구매요소는 순위+만족도가 모두 있어 구매요소 축 사분면 성립. 이유 컬럼이 `불편했던 점`·`개선 포인트` 2열로 분리

## 배정 시 주의점

- `위와 같이 평가한 이유는 무엇인가요?` 는 직전 문항에 종속 → 앞 문항과 같은 단계로 배정
- 개인정보(휴대폰 뒷자리·차량번호·연락처·계정)와 동의·인증·이미지 업로드는 전부 S0
- 값이 전부 빈 컬럼(투블럭 40·41 `가격 안내표`)도 S0
- 이젠오토 7열 `차량번호`는 인적사항 구간 한가운데 있지만 개인정보이므로 S0
