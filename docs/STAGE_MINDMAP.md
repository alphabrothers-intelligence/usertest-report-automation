## 읽는 법

### 근거

- 발행 보고서 4종의 `사용성 테스트 설문 항목` 표에서 단계 구분 직접 추출
- 리바랩스 37문항 / 케어클 37문항 / 이젠오토 30문항 / 투블럭 26문항
- raw data 5종 전 컬럼 대조 (전부 `data/` 폴더에 보관)

### 데이터셋 약칭

- 리바 = 리바랩스 · 캣독런 (62열)
- 케어 = 케어클 · 테크핏 (57열)
- 이젠 = 이젠오토 · 셀케어 (47열)
- 정리 = 정리습관 (54열)
- 투블 = 투블럭에이아이 · 키위티 (65열)

### 반복 컬럼 표기 규칙

- `위와 같이 평가한 이유는 무엇인가요?` 는 문항마다 1개씩 붙으므로 묶어서 1개 노드로 표기
- 실제 개수 — 리바 22개 · 케어 15개 · 정리 15개 · 이젠 11개

## S1 · 인적 사항 및 특성·경험 조사

### 인적사항 — 기본

- 나이를 입력해주세요 `리바` `케어` `이젠` `정리` `투블`
- 성별을 선택해주세요 `리바` `케어` `이젠` `정리`

### 특성 — 기기·신체·거주 조건

- 현재 사용하시는 스마트폰 운영체제를 선택해주세요 `리바`
- 피부 타입을 선택해주세요 `케어`
- 현재 소유하고 있는 차종을 적어주세요 `이젠` ⚠자유입력·집계제외
- 현재 거주 형태를 선택해주세요 `정리`
- 함께 거주 중인 가족 구성원 수를 선택해주세요 `정리`

### 특성 — 사용 습관·빈도

- 하루 평균 걷는 시간은 어느 정도인가요? `리바`
- 일주일에 몇 일 정도 산책을 하시나요? `리바`
- 연 주행거리(km)가 얼마나 되시나요? `이젠`
- 평소 글쓰기 활동 얼마나 자주 하시나요? (한 달 기준) `투블`

### 특성 — 숙련도·사전 경험

- 케어클의 '테크핏'을 체험하기 전, 다른 홈케어 뷰티 디바이스를 사용하고 계셨나요? `케어`
- 피부과에서 레이저/고주파 시술을 받은 경험이 있으신가요? `케어`
- 셀프 차량 정비에 대한 수준을 선택해주세요 `이젠` ⚠1~6단계 정의표 별도 첨부

### 특성 — 문제 인식 (사전 태도)

- 평소 집 정리나 수납이 어렵다고 느낀 적이 있으신가요? `정리`
- 집 정리를 할 때 가장 어려운 점은 무엇인가요? `정리`
- 현재 본인 상황에 해당하는 항목을 모두 선택해주세요 (중복 선택) `정리`

### 특성 — 소속·역할

- 어떤 학생들을 대상으로 가르치고 계신가요? `투블`
- 현재 어떤 곳에서 근무 중이신가요? `투블`

### ⚠ 단계 자체가 드롭될 수 있음

- 투블럭 보고서는 raw data에 인적사항 4문항이 있는데도 `Ⅱ. 인적 사항 및 특성·경험 조사` 장을 아예 만들지 않음
- 목차가 `Ⅰ. 개요` → `Ⅱ. 기능별 고객 경험 평가`로 바로 넘어감
- 판단 기준: 교차분석에 못 쓰거나(그룹 n 부족) 클라이언트가 불필요하다고 판단하면 드롭
