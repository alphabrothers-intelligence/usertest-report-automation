# 케어클 실제품 사용성테스트 보고서 렌더러 (v1)

케어클 원본 보고서의 **실제품형** 구성과 정량 도표 규칙을 독립적으로 구현한 검증용 렌더러입니다.
기존 SW/앱용 렌더러(`lib/pdf/**`, `lib/pdf-rivalabs-v3/**`)를 수정하거나 재사용하지 않습니다.

## 정량 분석 원칙

- 입력: `data/[케어클] 사용성테스트 raw data.csv`
- 계산: 로컬 TypeScript 계산만 사용합니다. Claude API 및 다른 외부 AI API를 호출하지 않습니다.
- 응답자 기준: 원본 데이터 27행에서 휴대전화 끝 4자리 기준으로 중복 응답 2건을 제거하여 **25명**을 분석 기준으로 사용합니다.
  - CSV가 응답 시각 내림차순이므로, 같은 휴대전화의 첫 행(가장 최근 응답)을 유지합니다.
- 산출: 인적사항, 기능 만족도, 고객 여정, 핵심구매요소, 4대 가치, 종합 만족도, NPS 및 순위 분포를 계산합니다.

## 실제품형 보고서 정책

실제품 보고서는 SW/앱형과 달리 다음 8개 장으로 구성합니다.

1. 개요
2. 인적 사항 및 특성 조사
3. 기능별 고객 경험 평가
4. 고객여정 기반 경험 평가
5. 핵심구매요소
6. 4대 가치 만족도
7. NPS 지수 및 종합 만족도
8. 종합 결과 및 제언

정성 분석이 아직 실행되지 않은 곳은 원본의 표/제목/여백을 유지한 채 `정성 분석 결과 대기` 영역으로 남깁니다. 정성 결과가 승인되면 대표 인용, 긍·부정 요약, 해석·제언만 해당 슬롯에 채우도록 설계했습니다.

## 실행

```bash
npx tsx scripts/render-carecl-v1.ts
```

결과 파일: `output/pdf/케어클_실물제품형_정량검증_v1.pdf`

## 현재 범위

이 버전은 원본 53쪽 전체를 문구까지 복제하는 최종본이 아니라, raw data 기반으로 재현 가능한 정량 결과와 실제품 전용 서식 정책을 검증하는 15쪽 PDF입니다. 이후 정성 분석을 별도 실행해 확정하면, 정성 전용 슬롯을 채운 확장본으로 발전시킵니다.
