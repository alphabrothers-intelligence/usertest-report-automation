# 리바랩스 격리 렌더러 v3

이 디렉터리는 사용자가 2026-07-23에 지정한 기존 Claude Code 렌더러(`lib/pdf/`)의
작업 사본이다. 원본 파일은 수정하지 않고, 리바랩스 원본 PDF와의 시각 대조·보정은 이 사본에서만
진행한다.

- 실행: `npx tsx scripts/render-rivalabs-v3.ts`
- 산출물: `output/pdf/리바랩스_원본재현_v3_격리렌더러.pdf`
- 비교 기준: `data/[알파브라더스] 리바랩스_사용성테스트_결과보고서_0904_상연.pdf`

## 아주 짧은 사용 가이드

1. 이 사본만 수정한다. `lib/pdf/`는 Claude Code 기준 원본이라 수정하지 않는다.
2. `npx tsx scripts/render-rivalabs-v3.ts`로 PDF를 다시 만든다.
3. `output/pdf/리바랩스_원본재현_v3_격리렌더러.pdf`와 원본 PDF를 페이지 이미지로 비교한다.
4. 이 결과를 앱의 기본 렌더러로 채택하려면, 검수 후에만 `lib/pdf-rivalabs-v3`의 변경을 `lib/pdf`로 선택 반영한다.

## 원본 재현 규칙

아래 규칙은 리바랩스 원본 PDF를 기준으로 한 의도적인 렌더링 계약이다. 새 기능을 추가할 때도
이 규칙을 우선한다.

- **표지**: 흰 배경과 큰 제목을 기본으로 하며, 회사명·발행일·로고는 `productInfo`의
  `companyName`, `coverDate`, `coverLogoUrl` 값을 사용한다. 값이 바뀌면 재생성 PDF에 반영한다.
- **서체와 위계**: Pretendard를 사용한다. 본문은 확대 없이 읽을 수 있는 크기를 유지하고,
  질문 문항은 과도한 굵은 글씨를 쓰지 않는다. 제목·소제목·표 머리말만 굵게 구분한다.
- **섹션/표 제목**: 로마 숫자 섹션 배너, 번호가 있는 소제목 박스, 청록 구분선, 연보라 제목
  밴드(`[ 응답 결과 ]` 등)의 순서와 색 체계를 유지한다. 제목 밴드 안의 글자는 검은색으로 쓴다.
- **차트**: 원본의 민트 막대, 파스텔 순위 막대, 축/눈금/범례/기준선을 모두 표시한다. 차트는
  정량 통계값만 입력으로 사용하며 렌더링 자체는 외부 AI 호출을 하지 않는다.
- **줄바꿈**: 한글 음절 단위 줄바꿈을 막고, 질문 번호와 본문을 분리해 둘째 줄이 질문 본문
  시작점 아래로 정렬되게 한다.
- **페이지 넘김**: 새 섹션 배너와 첫 콘텐츠는 함께 이동한다. 설문/요약 표의 단계 묶음은
  페이지 중간에서 분할하지 않으며, 페이지 끝에서는 하단 테두리로 닫고 다음 페이지에서는
  상단 테두리로 다시 시작한다.
- **검수 범위**: 현재 v3는 정량 데이터와 자리표시자 기반의 검증 렌더러다. 원본의 모든
  정성 해석/문항별 결과 페이지를 동일한 분량으로 채우려면 정성 분석 결과를 연결한 뒤,
  원본 56쪽과 재생성본을 다시 페이지 단위로 대조해야 한다.
